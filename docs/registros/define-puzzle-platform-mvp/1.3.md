## Arquitetura e revisão

A validação de ambiente fica em uma função que recebe as variáveis de configuração. Antes de ouvir, o servidor exige configuração válida e faz uma sondagem de escrita no diretório do banco. O Node executa os testes sem dependência adicional. Neste commit, o script de migração sinaliza a dependência da tarefa 2.1.

Arquivos revisados `api/src/config.js`, `api/src/server.js`, `api/test/config.test.js`, `package.json` e `.gitignore`.

## Evidências

No Windows com Node v24.22.3, `npm ci`, `npm run lint`, `npm run build` e `npm test` passaram. Os três testes cobriram o servidor e o processo iniciado com configuração inválida. `git check-ignore` confirmou a exclusão de `data/nexo.sqlite`, `.env.local` e do material local de referência.
