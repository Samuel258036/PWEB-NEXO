## Arquitetura e revisão

A raiz coordena os pacotes com um lockfile. O navegador monta um componente React em JavaScript/JSX. O Express começa como uma fábrica de aplicativo independente do processo HTTP. A página estática usa fundo escuro, texto verde monoespaçado e largura de leitura do guia visual local.

Arquivos revisados `package.json`, `web/package.json`, `api/package.json`, `web/src/` e `api/src/app.js`.

## Evidências

No Windows, com Node v24.11.1 e npm 11.6.2, `npm install`, `npm run lint` e `npm run build` passaram. A instalação foi repetida com acesso aos links de workspace após o sandbox bloquear sua criação.
