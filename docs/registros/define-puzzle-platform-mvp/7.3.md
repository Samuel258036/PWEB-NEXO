## Implementação

A confirmação descreve o congelamento do nome e da estrutura. A interface envia a versão salva e orienta salvar primeiro quando há alterações locais. Dentro da transação, o servidor confere a versão e os campos obrigatórios, inclusive quando o texto tem apenas espaços e quebras de linha.

## Verificações

No Chrome com API e SQLite locais, um rascunho incompleto mostrou o erro junto à resposta. As alterações locais bloquearam a publicação até o salvamento. O cancelamento manteve o estado de rascunho. A confirmação abriu o mesmo enigma por nome na API de jogo. Lint, build e os seis testes de autoria passaram.
