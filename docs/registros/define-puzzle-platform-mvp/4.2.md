## Arquitetura

`PUT /api/author/puzzles/:id/draft` valida todo o payload antes da escrita. Repositório verifica autoria, status e versão dentro de transação imediata. Etapas existentes mudam de posição temporariamente para evitar colisões UNIQUE; IDs listados são atualizados, etapas sem ID são inseridas e etapas omitidas são removidas (com cascata de dicas). As dicas das etapas preservadas não são alteradas.
