## Arquitetura e revisão

O Vite encaminha `/api` ao Express durante o desenvolvimento. Em produção o Express atende primeiro a API, depois os arquivos reais e por fim as navegações que aceitam HTML. O servidor fica separado de `createApp` para que os testes possam abrir uma porta temporária.

Arquivos revisados `web/vite.config.js`, `api/src/app.js`, `api/src/server.js` e `api/test/http.test.js`.

## Evidências

No Windows com Node v24.22.3, `node --test api/test/http.test.js` passou. Com o build real, a rota direta `/criadores` retornou HTTP 200 e mostrou “O que você busca?” no Chrome. O pedido a `/api/health` pela porta do Vite devolveu `{"status":"ok"}`.
