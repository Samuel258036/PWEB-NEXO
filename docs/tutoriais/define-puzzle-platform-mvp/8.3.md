# 8.3. Testar o reinício e a restauração em cópia

Na raiz do projeto, execute o ensaio com um volume descartável.

```powershell
node --test api/test/operations.test.js
```

O teste aplica a migração, grava progresso, faz o backup com o processo ativo e completa uma requisição durante o encerramento. Em seguida, abre o mesmo arquivo e uma cópia restaurada. Em ambos os casos, o cookie existente retorna a sessão e o progresso salvos.
