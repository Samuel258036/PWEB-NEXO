# 3.5. Conferir uma sessão pela API

Você vai identificar um nome em uma API local e conferir quando o servidor cria a conta.

1. No terminal da API, defina `DATABASE_PATH` para um arquivo novo de teste. Inicie a API conforme o [README](../../../README.md), com a porta 3000 e a origem `http://localhost:5173`.
2. Em outro PowerShell, obtenha o cookie de sessão e o token CSRF. A coluna `user` fica vazia porque a sessão é anônima.

   ```powershell
   $api = 'http://localhost:3000/api/auth'
   $initial = Invoke-RestMethod "$api/session" -SessionVariable nexo
   $headers = @{ Origin = 'http://localhost:5173'; 'X-CSRF-Token' = $initial.csrfToken }
   $initial | Select-Object user
   ```

3. Consulte o nome. A API retorna `state: new` porque o banco está vazio.

   ```powershell
   $common = @{ Method = 'Post'; WebSession = $nexo; Headers = $headers; ContentType = 'application/json' }
   Invoke-RestMethod "$api/identify" @common -Body '{"username":"Pessoa Demo"}'
   ```

4. Cadastre a conta com confirmação explícita. A resposta contém `user.usernameDisplay` igual a `Pessoa Demo`. Use a senha de exemplo somente no banco de teste.

   ```powershell
   $registered = Invoke-RestMethod "$api/register" @common -Body '{"username":"Pessoa Demo","password":"senha local de exemplo","confirmedNew":true}'
   $registered.user
   ```

O cookie guardado em `$nexo` foi atualizado no cadastro. Antes do próximo `POST`, substitua `$headers['X-CSRF-Token']` pelo token de `$registered.csrfToken`.
