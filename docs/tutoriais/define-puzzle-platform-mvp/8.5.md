# 8.5. Repetir a verificação integrada

Prepare o Chromium e o ambiente de teste conforme a [tarefa 8.1](8.1.md). Na raiz, execute.

```powershell
npm run lint
npm test
node --test web/src/*.test.js
npm run test:e2e -- --workers=1
```

Confira o build, os 54 testes da API, os 9 da interface e os 4 cenários Playwright. Cada cenário de navegador usa um banco descartável com HTTPS local. O [registro da revisão](../../registros/define-puzzle-platform-mvp/8.5.md) relaciona as verificações às quatro especificações e registra o que ainda depende do piloto.
