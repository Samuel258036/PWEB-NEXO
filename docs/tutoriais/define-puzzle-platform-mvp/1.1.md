# 1.1. Base JavaScript com npm workspaces

1. Na raiz, rode `npm ci` para instalar os dois pacotes pelo lockfile compartilhado.
2. Rode `npm run dev` e abra o endereço exibido. `web/index.html` carrega `web/src/main.jsx`, que monta a pergunta inicial.
3. Rode `npm run build`. Confira a saída em `web/dist/`.

Veja as decisões e evidências no [registro da tarefa](../../registros/define-puzzle-platform-mvp/1.1.md).
