# 5.6 — Corridas HTTP concorrentes e recriação de enigma

## O que foi entregue

Adicionamos testes HTTP concorrentes para verificar o comportamento do sistema em corridas entre envio de resposta e edição de etapa, entre envio de resposta e exclusão do enigma, e na recriação de um enigma com o mesmo nome sem progresso reaproveitado.

## Arquivos principais

- `api/src/repositories.js`: transações `IMMEDIATE`, controle otimista de versão e remoção em cascata na exclusão de enigmas.
- `api/test/play.test.js`: testes de concorrência HTTP (`Promise.all`) e verificação de ausência de progresso após recriação.
- Registro: [5.6](../../registros/define-puzzle-platform-mvp/5.6.md).
