# 6.6. Retomar uma partida após falha de conexão

Quando uma resposta do servidor se perde, o campo conserva o texto digitado. Você pode reenviar e continuar do ponto em que o servidor registrou o progresso.

1. Inicie o Nexo conforme o [README](../../../README.md). Em um banco de teste, publique um enigma com duas etapas que aceitam a mesma resposta. Use os exemplos da [API de autoria](../../api-autoria.md).
2. Abra o enigma em duas abas com a mesma conta de jogador. As duas exibem a primeira etapa. A segunda aba reproduz um reenvio com uma versão antiga, como acontece se a primeira resposta do servidor se perder.
3. Acerte na primeira aba. Ela exibe a segunda etapa.
4. Envie a mesma resposta na segunda aba. Ela exibe “A partida foi atualizada.” e também fica na segunda etapa. O código envia a etapa e a versão exibidas, por isso o servidor reconhece o segundo pedido como desatualizado.
5. Com a partida aberta, use outro perfil do navegador ou cliente HTTP para excluir o enigma de teste pela API de autoria. Envie uma resposta na aba do jogador. A tela remove o desafio, exibe “Não encontramos esse nexo.” e permite voltar por **Início**.
