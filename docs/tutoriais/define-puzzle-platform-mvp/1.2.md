# 1.2. Proxy e entrega do build

1. Rode `npm run dev:api` e, em outro terminal, `npm run dev`. Abra `/api/health` no endereço mostrado pelo Vite.
2. Rode `npm run build` e `npm start` conforme o [README](../../../README.md#servir-o-build-localmente). Abra `/criadores` no endereço do Express e confira a tela inicial.
3. Acesse `/api/inexistente` e confira o 404 com corpo JSON.

Veja as decisões e evidências no [registro da tarefa](../../registros/define-puzzle-platform-mvp/1.2.md).
