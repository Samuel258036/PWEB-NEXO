# 8.2. Conferir foco, contraste e dados do terminal

Prepare o navegador conforme a [tarefa 8.1](8.1.md). Na raiz do projeto, execute.

```powershell
npm run test:e2e -- accessibility.spec.js --workers=1
```

Os dois cenários usam a interface real. O teste verifica a pergunta da primeira visita, percorre os controles com teclado e compara as cores computadas. Depois, inspeciona as respostas da API antes de pedir uma dica, após revelá-la, ao avançar e ao concluir.
