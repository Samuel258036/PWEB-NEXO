# 4.3. Publicar um enigma

## O que foi implementado

O autor publica o rascunho persistido enviando sua versão atual a `POST /api/author/puzzles/:id/publish`. A publicação exige pelo menos uma etapa com enunciado e resposta. Dicas e mensagem final são opcionais. Depois de publicado, o salvamento de estrutura de rascunho é recusado.
