# 4.1. Criar e retomar rascunhos

## O que foi implementado

A API de autoria lista os enigmas da conta, cria um rascunho ao reservar seu nome e permite retomá-lo pelo ID. A leitura é limitada à conta autenticada; outra conta recebe `404 NOT_FOUND`.

Na raiz do projeto: `node --test api/test/author.test.js`. O teste verifica criação, listagem, retomada e bloqueio de leitura entre contas.
