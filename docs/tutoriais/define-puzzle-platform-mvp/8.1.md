# 8.1. Testar autoria e jogo em HTTPS

Use Node.js 24 e deixe o comando `openssl` disponível no PATH. Na raiz do projeto, execute no PowerShell.

```powershell
npm ci
$env:PLAYWRIGHT_BROWSERS_PATH = Join-Path (Get-Location) 'data/playwright-browsers'
npx playwright install chromium --only-shell
npm run test:e2e
```

O comando compila o site e executa um cenário Playwright. O Chromium abre dois contextos, um para a autora e outro para a jogadora. O cenário passa quando o rascunho pode ser retomado e publicado, a dica e a partida sobrevivem ao novo login, a primeira resposta fica bloqueada e a exclusão retira a conclusão da tela da jogadora.

O servidor de teste gera um certificado temporário, aplica a migração em um SQLite novo e serve o build numa porta local. A aceitação do certificado vale para os contextos de teste. Os arquivos de diagnóstico ficam em `data/test-results/e2e`. [Instalação de navegadores no Playwright](https://playwright.dev/docs/browsers)
