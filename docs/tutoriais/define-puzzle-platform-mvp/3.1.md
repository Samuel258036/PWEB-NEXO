# 3.1. Derivar e verificar senhas

## O que foi entregue

A API agora tem funções assíncronas para criar e verificar hashes de senha com `scrypt`, salt aleatório e formato versionado. A senha é comparada exatamente como foi informada, incluindo maiúsculas, minúsculas e espaços. O processamento é limitado a um hash ativo e quatro em espera.

Esta tarefa criou funções internas. Ainda não há rotas HTTP de cadastro ou login para chamá-las.

## Arquivos

- [Hash e verificação de senhas](../../../api/src/passwords.js).
- [Testes de senhas](../../../api/test/passwords.test.js).
- [Registro da tarefa 3.1](../../registros/define-puzzle-platform-mvp/3.1.md).

## Como conferir

Na raiz do projeto, execute:

```powershell
node --test api/test/passwords.test.js
```

Os quatro testes devem passar. Eles verificam senhas corretas e incorretas, diferenças de caixa e espaços, formato inválido, limite da fila e ausência de credenciais em logs e mensagens de erro.
