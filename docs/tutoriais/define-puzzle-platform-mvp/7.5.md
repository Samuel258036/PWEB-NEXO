# 7.5. Excluir um enigma com confirmação

1. Em um banco local de teste, abra um enigma salvo na lista de autoria.
2. Selecione **Excluir enigma**, leia o aviso e cancele. O editor continua aberto.
3. Selecione a ação de novo e confirme. Confira a lista atualizada. Crie e salve outro rascunho com o mesmo nome para verificar que ele ficou disponível.
