# 2.1. SQLite e primeira migração

1. Em um terminal com a configuração padrão local, rode `npm run migrate`. Em um banco vazio, o comando cria o esquema e registra a versão `0001`.
2. Execute o mesmo comando novamente. O número de migrações aplicadas deve ser 0, porque a versão já está em `schema_migrations`.
3. Rode `npm test`. Os testes usam arquivos temporários e verificam a persistência ao reabrir, a etapa vinculada ao enigma e o rollback.
4. Para entender a inicialização, siga `api/src/server.js` até `migrateDatabase`, em `api/src/database.js`, e compare o esquema com `api/migrations/0001_initial_schema.sql`.

Veja as decisões e evidências no [registro da tarefa](../../registros/define-puzzle-platform-mvp/2.1.md).
