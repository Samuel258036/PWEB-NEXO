# 8.4. Preparar uma sessão piloto

1. Abra o [roteiro](../../piloto.md) e prepare o ambiente e um enigma com dados de teste.
2. Use a seção de jogador na primeira visita. Reserve a seção de autoria para quem vai criar enigmas.
3. Registre o que cada pessoa fez, a ajuda de que precisou e o motivo que relatou para continuar ou parar.
