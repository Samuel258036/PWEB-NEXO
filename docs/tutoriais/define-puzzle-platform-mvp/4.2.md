# 4.2. Salvar e ordenar um rascunho

## O que foi implementado

`PUT /api/author/puzzles/:id/draft` salva o nome e o snapshot das etapas de um rascunho. A requisição envia a versão esperada e IDs estáveis para etapas existentes; etapas sem ID são novas. A ordenação das etapas é definida pela ordem da lista enviada. Dicas não são reorganizadas por esta rota.

Conflito de versão ou nome retorna `409`; IDs de etapas que não pertencem ao enigma retornam `404`.
