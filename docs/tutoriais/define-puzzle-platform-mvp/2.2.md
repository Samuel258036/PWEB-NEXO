# 2.2. Validar nomes, respostas e limites

## O que foi entregue

A API agora tem funções para validar nomes de usuário e enigma, respostas, senhas e textos de enunciado, dica e conclusão. Nomes e respostas ganham uma chave para comparação sem diferenciar maiúsculas/minúsculas e espaços externos. A senha continua exatamente como foi informada. Esta etapa cria os validadores; as rotas que vão usá-los serão implementadas depois.

## Como conferir

Na raiz do projeto, execute:

```powershell
node --test api/test/validation.test.js
```

Os oito testes devem passar. Eles cobrem caixa, espaços externos e internos, acentos, pontuação, respostas reservadas, limites Unicode, controles e preservação da senha.
