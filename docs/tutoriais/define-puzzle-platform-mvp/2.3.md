# 2.3. Criar repositórios e proteger referências

## O que foi entregue

A API agora prepara consultas SQL para localizar e criar contas, reservar enigmas, consultar enigmas pela autoria e registrar partidas, soluções e dicas reveladas. Uma tentativa de relacionar uma partida a uma etapa ou dica de outro enigma é recusada pelo repositório. O índice `UNIQUE` do SQLite continua decidindo conflitos de nomes equivalentes.

## Como conferir

Na raiz do projeto, execute:

```powershell
node --test api/test/repositories.test.js
```

Os testes usam o SQLite embutido no Node para criar um arquivo temporário, aplicar a migração inicial e verificar reservas repetidas, autoria e referências entre enigmas. A integração dos repositórios com o `better-sqlite3` usado pela aplicação ainda precisa ser conferida quando as dependências estiverem instaladas.
