# 2.4. Agrupar escritas e controlar versões

## O que foi entregue

A persistência agora oferece uma transação síncrona para manter várias escritas juntas: se uma falha, as anteriores são desfeitas. Também permite avançar a versão de um enigma ou partida somente quando a conta e a versão esperada correspondem. Uma versão antiga gera conflito e não substitui a mais recente.

## Como conferir

Na raiz do projeto, execute:

```powershell
node --test api/test/transactions.test.js api/test/repositories.test.js api/test/validation.test.js
```

Os 14 testes devem passar. Eles usam o SQLite embutido no Node em arquivos temporários e verificam rollback, callbacks assíncronos e conflitos de versão. A integração com `better-sqlite3`, o lint e a suíte completa ainda precisam ser conferidos após instalar as dependências; não foram executados nesta sessão.
