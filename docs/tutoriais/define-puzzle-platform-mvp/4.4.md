# 4.4. Manter o conteúdo publicado

## O que foi escrito

A API permite editar enunciados e a mensagem final, e incluir, editar e remover dicas. Resposta de etapa fica bloqueada após o primeiro acerto; enunciado permanece editável. Dicas novas são anexadas ao fim da lista e não existe operação para reordená-las ou pausar o enigma.
